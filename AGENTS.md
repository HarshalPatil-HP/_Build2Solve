# SahiScan working rules

1. Work on one clearly scoped task at a time.
2. Use one Git branch per task.
3. Do not call work "done" without the command run and a short output snippet.
   If it was not tested, write `UNTESTED`.
4. Do not edit files outside the agreed task scope.
5. Do not change `Backend/src/services/ruleEngine.service.js` without explicit
   approval. Legal rule logic must remain reviewable for the project viva.
6. Keep code small, readable, and commented where the reason is not obvious.
7. Never print environment values, tokens, passwords, or keys.
8. Update `STATUS.md` after every completed task.
